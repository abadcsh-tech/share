Why Markdown

왜 MD를
'원본'으로 두는가.

포맷이 한 번 닫히면, 다른 포맷으로 옮기는 일은 매번 깨집니다. 가장 개방적이고, 가장 AI 친화적인 포맷에서 출발해야 — 모든 변환이 자유로워집니다.

Markdown

평문 · 텍스트 · 오픈 표준
AI 가독성100%
변환 깨짐 위험낮음
용량~수 KB
사람이 직접 편집메모장으로도 가능

PPTX / DOCX

바이너리 · 폐쇄적 포맷
AI 가독성35%
변환 깨짐 위험매우 높음
용량수 MB+
사람이 직접 편집전용 앱 필요

PPT를 한 번 만들어두면 그것은 그저 PPT일 뿐입니다. Word로, 웹으로 옮기는 순간 포맷이 깨집니다. MD는 다릅니다 — MD에서 PPT로 가는 길은 열려 있고, 거꾸로는 막혀 있습니다.

Workflow

전체 흐름은
이렇게 작동합니다.

Claude Code가 만들고 → 옵시디언이 보여주고 → 필요할 때 다른 포맷으로 변환합니다. 세 도구가 같은 .md 파일을 공유하기 때문에, 어디서 작업해도 깨지지 않습니다.

1
Claude Code로 만든다

"이번 주 설교 노트 정리해줘" — 자연어로 부탁하면 Claude Code가 정돈된 .md 파일로 출력합니다.

2
옵시디언이 보여준다

같은 폴더(볼트)를 옵시디언이 읽어, 위키링크·태그·그래프뷰까지 살아있는 노트로 그려줍니다.

3
옵시디언에서 직접 다듬는다

설교 원문 다듬기, 위키링크 걸기, 메모 추가 — 옵시디언 안에서 자유롭게 편집합니다. 파일은 여전히 .md.

4
다시 Claude Code에게 변환을 부탁한다

"이걸 PPT로 만들어줘", "교사용 DOCX로 묶어줘" — 같은 원본에서 필요한 형식만 그때그때 뽑습니다.

5
원본은 하나, 출력은 무한

주일에는 PPT, 월간 자료는 DOCX, 공유는 HTML, SNS는 인포그래픽 — 모두 같은 .md에서 출발합니다.
